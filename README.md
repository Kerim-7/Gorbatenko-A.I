# Gorbatenko A.I.

Лендинг доктора Горбатенко А.И. — хирургия стоп и коленных суставов.

## Актуальный сайт (React + TypeScript)

```bash
cd web
npm install
npm run dev
```

Сборка: `npm run build`  
Превью: `npm run preview`

SEO, контент и структура — в `web/README.md`.

Статический прототип (HTML) лежит в `site/` — основной продукт теперь `web/`.
